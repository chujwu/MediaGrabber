

# 📺 YouTube/B站视频下载器

> 基于 yt-dlp 的现代化视频下载工具，支持 YouTube、B站等多平台

---

## 🎯 项目特色

✅ **多平台支持** - YouTube、B站、Twitter、Instagram 等 1000+ 网站  
✅ **现代化 UI** - PyQt6 构建，界面美观易用  
✅ **Cookies 认证** - 支持 YouTube 登录认证下载  
✅ **代理管理** - 智能代理切换，支持系统/自定义代理  
✅ **批量下载** - 支持批量添加下载任务  
✅ **格式转换** - 支持多种视频/音频格式  
✅ **字幕下载** - 支持自动/手动字幕下载

## ⚡ 快速开始

### 1. 安装依赖

```bash
# 方法 1: 使用批处理脚本（Windows）
双击运行 "安装依赖.bat"

# 方法 2: 手动安装
pip install -r requirements.txt
pip install "yt-dlp[default]"
```

> 如需使用视频/音频格式转换功能，请安装 [ffmpeg](https://ffmpeg.org) 并确保其在系统 `PATH` 中。

### 2. 配置 YouTube 支持（可选）

如需下载 YouTube 视频，需要安装 **Deno**（JavaScript 运行时）：

```powershell
# PowerShell 管理员模式
irm https://deno.land/install.ps1 | iex
```

### 3. 导入 Cookies（YouTube 登录认证）

程序内置 Cookies 管理功能，可在主界面中直接操作：

1. 点击「📥 导入」按钮
2. 粘贴浏览器导出的 Cookies 内容
3. 点击确定完成导入

详细操作方法请见下方"Cookies 管理"章节。

### 4. 启动程序

```bash
# 方法 1: 使用批处理脚本（Windows）
双击运行 "启动程序.bat"

# 方法 2: 命令行启动
python main.py
```

## 🔧 功能说明

### 代理设置（v2.0 全新设计）

#### 三种模式：

1. **不使用代理**
   - 直连模式，不使用任何代理
   - 适用于国内网站（如B站）

2. **使用系统代理** ⭐ 推荐
   - 自动检测系统代理设置
   - 支持 Windows 注册表和环境变量
   - 默认启用

3. **使用自定义代理**
   - 手动输入代理地址
   - 支持 SOCKS5 和 HTTP 代理
   - 内置连接测试功能

#### 代理测试：

- 输入代理地址（如 `socks5://127.0.0.1:7890`）
- 点击"测试连接"按钮
- 等待测试结果（绿色成功/红色失败）
- 成功后自动应用

### Cookies 管理

#### 功能：

- **查看** - 显示已保存的 Cookies 详细信息
- **导入** - 从浏览器导出的内容导入
- **清除** - 删除已保存的 Cookies 文件

#### 导入方法：

1. 安装 Chrome 扩展："Get cookies.txt LOCALLY"
2. 访问 youtube.com 并登录
3. 点击扩展图标，选择"Export"
4. 将内容粘贴到导入对话框
5. 点击确定，自动保存

### 下载功能

#### 支持格式：

- **视频**: MP4, MKV, WebM
- **音频**: MP3, M4A, WAV, FLAC

#### 质量选项：

- 最高质量（原始）
- 1080p, 720p, 480p, 360p
- 最低质量

#### 字幕选项：

- 不下载字幕
- 仅自动生成字幕
- 仅手动字幕
- 全部字幕

## 🐛 故障排除

### YouTube 视频无法获取

**症状：** 

```
WARNING: Signature solving failed
ERROR: Requested format is not available
```

**解决方案：**

1. 安装 Deno（见"快速开始"）

2. 确保 yt-dlp 为最新版本：

   ```bash
   pip install --upgrade "yt-dlp[default]"
   ```

3. 检查 Cookies 是否过期

4. 检查代理设置是否正确

### B站视频无法下载

**可能原因：**

1. 网络连接问题
2. 视频链接无效
3. 视频已被删除

**解决方案：**

1. 检查网络连接
2. 尝试切换代理模式
3. 使用浏览器确认视频可访问

### 代理测试失败

**可能原因：**

1. 代理地址错误
2. 代理服务未启动
3. 防火墙阻止

**解决方案：**

1. 确认代理地址格式正确
2. 检查代理软件是否运行
3. 尝试关闭防火墙测试
